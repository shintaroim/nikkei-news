# 日経新聞 主要ニュース取得

今日の日経新聞の主要ニュースを取得し、カテゴリ別に整理して報告する。

## 手順

1. WebFetch が未ロードなら `ToolSearch` で `select:WebFetch` を実行してロードする。
2. 次の2つを **並列で** WebFetch する。
   - `https://www.nikkei.com/` — プロンプト:「トップページに掲載されている主要ニュースの見出しを、記事URLと短い要約（リード文があれば）付きで、掲載順に最大20件列挙してください。カテゴリ（経済・政治・企業・マーケット・国際など）が分かれば併記。ページに表示されている日付も教えてください。」
   - `https://assets.wor.jp/rss/rdf/nikkei/news.rdf`（日経速報RSS）— プロンプト:「RSSに含まれる記事の見出し・URL・日時・概要をすべて列挙してください。」
3. 両方の結果を統合する。
   - トップページ掲載記事を「主要ニュース」として優先し、掲載順を重要度とみなす。
   - RSS で URL・掲載時刻を補完する。RSS のみの記事は「その他の注目記事」に回す。
   - 重複は統合する。今日（または直近24時間）以外の記事は除外する。
4. どちらかの取得に失敗した場合は、もう一方の結果で報告し、失敗した旨を一言添える。両方失敗した場合は `WebSearch` で「日経新聞 今日 主要ニュース」を検索して代替する。
5. 結果を下記「出力形式」でユーザーに表示する。
6. 表示した後、同じ内容をローカルに保存する。
   - 保存先: プロジェクトルートの `news/YYYY-MM-DD.md`（例: `news/2026-10-07.md`）。`news/` が無ければ作成される（Write ツールで直接書けばよい）。
   - ファイル内容は表示した Markdown と同一にし、末尾に `取得日時: YYYY-MM-DD HH:MM` を付ける。
   - 同じ日付のファイルが既にある場合は、Read してから最新の取得結果で上書きする。
   - 最後に保存先パスをリンク形式で一言伝える。

## 出力形式

```
## 日経新聞 主要ニュース（YYYY年M月D日）

### 主要ニュース（トップページ掲載順）
1. **[カテゴリ] 見出し** — 1行要約 ([記事](URL))
...

### カテゴリ別の注目記事
- **マーケット**: ...
- **企業**: ...
- **国際**: ...
- **政治・経済政策**: ...

### 今日のポイント
- 全体を通した傾向を2〜3行で（例：AI関連、金利・為替動向など）
```

## 注意

- 日経の記事本文は有料会員限定が多い。見出しとリード文の範囲で要約し、本文を推測で補わない。
- 要約は事実ベースで簡潔に。URL は取得できたもののみ記載する。
- 最後に出典（nikkei.com）を記載する。
